## 🎮 О игре

**«Змея и Дождик»** — атмосферная 3D-аркада в сеттинге ночного дождя. Вы управляете мистической красной змеёй, которая должна поймать **15 капель дождя** за **3 минуты**, избегая ударов молний.

Игра создана в рамках проекта **Anti-AI Shield** — серии независимых игр с уникальным визуальным стилем.

### ✨ Ключевые особенности

- 🌙 **Атмосферный 3D-мир** — звёздное небо, плывущая луна, облака, деревья, светящиеся цветы и лужи с рябью
- 💧 **Капли в форме настоящей капли** — через `LatheGeometry` с свечением и золотыми бонусными каплями
- ⚡ **Разветвлённые молнии** — с фазой предупреждения, вспышкой неба и screen shake
- 🔥 **Комбо-система** — множители ×1 → ×2 → ×3 с огненной анимацией HUD
- 🚀 **Рывок (Dash)** — ускорение ×3 с золотым следом и кулдауном
- 💎 **3D-осколки** — разлетающиеся тетраэдры с физикой при поимке капель
- 📳 **Тактильная отдача** — вибрация на мобильных устройствах
- 🔊 **Процедурный звук** — WebAudio API без внешних файлов
- 🗣️ **Голосовые подсказки** — через Speech Synthesis API (RU/EN)
- 🌍 **Двуязычность** — полный перевод интерфейса RU ↔ EN
- 📈 **Прогрессивная сложность** — молнии бьют чаще к концу игры
- 🧭 **Индикатор капли** — стрелка-помощник для мобильных игроков
- 🏆 **Доска почёта** — интеграция с глобальным лидербордом
- 🎁 **Награда за победу** — уникальная «Красная змея»

## 🎯 Геймплей

### Цель
Поймать **15 капель** дождя за **3 минуты**.

### Правила

| Элемент | Описание |
|---|---|
| 💧 **Обычная капля** | +1 очко × множитель комбо |
| ⭐ **Золотая капля** | +3 очка × множитель комбо (20% шанс) |
| ⚡ **Молния** | -5 секунд, сброс комбо, неуязвимость 1 сек |
| 🔥 **Комбо ×2** | после 3 капель подряд |
| 🔥🔥 **Комбо ×3** | после 6 капель подряд (максимум) |
| 🚀 **Рывок** | ускорение ×3 на 0.3 сек, кулдаун 1 сек |

### Награды
- 🏆 **Победа** → +1 «Красная змея» на Доску почёта
- 💀 **Поражение** → 0 змей, но попытка засчитывается

### 💻 Десктоп

| Клавиша | Действие |
|---|---|
| `←` / `→` | Поворот змеи |
| `↑` | Ускорение (до ×2) |
| `↓` | Замедление |
| `Space` | 🚀 Рывок |

Экранные кнопки:
- **◀ ▶** — поворот
- **▲ ▼** — газ/тормоз
- **🚀** — рывок (большая золотая кнопка)

**Индикатор 💧** — показывает направление к ближайшей капле.

## 💻 Технологии

| Технология | Назначение |
|---|---|
| **Three.js r128** | 3D-рендеринг, сцена, шейдеры |
| **HTML5 / CSS3** | UI, анимации, glassmorphism |
| **Vanilla JavaScript** | игровая логика (ES6+) |
| **WebGL** | аппаратное ускорение |
| **WebAudio API** | процедурный звук |
| **Speech Synthesis** | голосовые подсказки |
| **Vibration API** | тактильная отдача |
| **GLSL Shaders** | небо с градиентом и вспышкой |

### Архитектурные решения

- ✅ **LITE / FULL режимы** — автодетект слабых устройств через `deviceMemory` + `hardwareConcurrency`
- ✅ **Кеш геометрий** (`DROP_GEO_CACHE`, `SHARD_GEOMETRY`) — экономия GPU памяти
- ✅ **Пул частиц** — переиспользование спрайтов вместо создания новых
- ✅ **FPS limiter** — 45 FPS на мобильных, 60 на ПК
- ✅ **Защита от утечек** — `disposeMesh()` с проверкой `userData.shared`
- ✅ **Тройной CDN-фоллбэк** для Three.js (cdnjs → unpkg → jsdelivr)
- ✅ **WebP + JPG фоллбэк** для старых Safari
- ✅ **Оптимизация рендера** — в меню сцена рендерится один раз
